# 🎮 Curso de Java para Estudiantes de Secundaria: "Aventura POO: Batalla de Monstruos"

## 📋 Información del Curso

**Nombre del repositorio:** `java-fundamentals-course-Energix`  
**Organización:** Energix-Course-Java  
**Público objetivo:** Estudiantes de secundaria (12-17 años)  
**Duración total:** Aproximadamente 1 hora   
**Modalidad:** Videos de YouTube no listados + Editores online  

## 🎯 Objetivo del Curso

Este curso introduce a estudiantes de secundaria a los conceptos fundamentales de la programación orientada a objetos (POO) usando Java. A través de un proyecto emocionante de batalla de monstruos, los estudiantes aprenderán programación de manera práctica y divertida.

## 🌟 Por qué es Llamativo (12-17 años)

- **Temática de Juego:** Creación de personajes, estadísticas (vida, ataque), y combate tipo RPG
- **POO Visual:** Los estudiantes ven cómo las clases sirven como plantillas para crear diferentes enemigos
- **Progresión Simple:** Empieza con "Hola Mundo" y termina con un juego completo interactivo
- **Sin Instalaciones:** Todo funciona 100% online usando editores web

## 📚 Secuencia de Lecciones

### Lección 1: Tu Primer Héroe 
**Conceptos:** Introducción a Java, entrada/salida básica con Scanner

Aprende qué es un programa y por qué Java es ideal para empezar. Escribiremos el primer código para que la computadora te salude y te pregunte tu nombre.

---

### Lección 2: Tu Primera Batalla
**Conceptos:** Variables, tipos de datos (int, String), operadores y expresiones

Definiremos los datos esenciales de nuestro Héroe (nombre, vida, ataque) usando variables y tipos de datos. Aprenderemos a hacer cálculos básicos con operadores para definir el daño.

---

### Lección 3: Múltiples Enemigos 
**Conceptos:** Estructuras if-else, métodos (funciones) y parámetros

Usaremos las estructuras de control (if-else) para ver si un ataque tiene éxito. Crearemos nuestra primera función (método) como `calcularDaño` para reutilizar el código.

---

### Lección 4: Organiza tu Código 
**Conceptos:** POO básica (clases, objetos, constructores), encapsulación (getters/setters)

Daremos el salto a la POO. Crearemos la Clase Personaje (la plantilla) y la usaremos para crear el Objeto Heroe y el Objeto Monstruo. Luego, usaremos getters/setters para proteger los atributos.

---

### Proyecto Final: Juego Completo 
**Conceptos:** Bucles (for, while), arrays, desarrollo de programa completo, mejores prácticas

Uniremos todo usando un bucle while para que la batalla continúe hasta que la vida de alguien llegue a cero. Terminaremos introduciendo cómo usar un array para registrar varios monstruos.

---
